# 架构详解

## 五层 + 九环节

```
L0  输入层         原始四诊（症状 / 病史 / 自诉舌象 / 脉象可缺失）
L1  分诊层         红旗规则（一票否决）+ 轻量 LLM（仅可上调）
L2  规范化层       同义词词典 → 向量近义 → 否定检测
L3-A 检索前       三路召回 → RRF → Rerank → 拒答闸门
L4  主 Agent 层    1 个 Agent → 嵌套 Diagnosis + 5 验证器
L3-B 检索后       图谱路径校验 + 出处回填（属于验证器）
L5  核验层         并行 2 项 → 代码计算 confidence_score
L6  安全层         确定性闸门，反畏/妊娠/毒性/药典 → 命中即拒
L7  输出层         结构化处方 + 证据链 + 缺失声明 + 免责声明 + 落库
```

## 关键边界

### Agent 内部 vs Agent 外部

| 在 Agent 内部（验证回路） | 在 Agent 外部（流水线编排） |
|---|---|
| `@output_validator` × 5 | 分诊、规范化、检索 |
| `ModelRetry` 触发重生成 | 安全闸门（一票否决） |
| `output_type=Diagnosis` | `FinalOutput`（含拒诊/拒答/低置信/出方/拦截五种状态） |

### 图谱的两段使用

- **生成前检索**（L3-A）：教材条文 + 相似医案 → 注入 prompt
- **生成后核验**（L3-B）：图谱路径存在性 + 出处回填 → 属于 V1 / V4 验证器

> **不要把"溯源"当成一个并行辅助 agent 跑一遍、结果不进输出**。这等于白跑。

## 剂量计算三段式（v1.1）

```
基础方表 × TIER_MULTIPLIER[毒性][档位] × ROLE_MULTIPLIER[角色]
→ clamp 到药典区间
```

**毒性三级**：

| 毒性 | 常量档 | 高档 |
|---|---|---|
| 无毒 | 区间中位数 | × 1.4 |
| 有毒 | 区间下限 × 1.2 | × 1.0（不放大） |
| 大毒 | 锁定药典下限 | 不开放 |

**特殊管控药材**（附子、川乌、草乌、马钱子、细辛、半夏、巴豆、甘遂、大戟、芫花、天南星）：
- 跳过公式，直接取药典下限
- 强制 `review_required=True`

## confidence_score 公式（v1.1）

```
score = 0.35 * (verifiers_passed / 5)
      + 0.25 * normalize(rerank_top_score)
      + 0.20 * (1 if graph_covered else 0.5)
      + 0.10 * (1 if case_alignment_ok else 0)
      + 0.10 * (1 - missing_penalty)
```

**缺信息惩罚**（v1.1 修正）：
- 缺脉象：0（脉象在远程场景默认缺失）
- 缺舌象：+0.5
- 核心症状 < 3：+0.5
- **缺舌象 + 核心症状 < 3**：直接拒答，不出方
